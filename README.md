# hoctienganh
 Hệ thống là nền tảng học tiếng Anh trực tuyến theo lộ trình, kết hợp bài học, nhiệm vụ, quiz, luyện nghe, AI nhận diện hình ảnh và gamification. Giao diện thân thiện, vui nhộn như trò chơi, có pet đại diện, hỗ trợ học viên, phụ huynh, giáo viên và quản trị viên theo vai trò riêng, giúp theo dõi tiến trình, quản lý nội dung và mở rộng lâu dài.
